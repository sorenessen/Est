# Est visual development history

This directory preserves screenshots from Est's development as a visual record
of the project as it evolves.

These images are historical artifacts, not generated build output. They should
normally remain in version control even after the implementation they depict
has changed or been replaced.

## Convention

Prefer screenshots that capture meaningful milestones, experiments, rendering
changes, simulation behavior, or other visible progress.

Keep the capture date in the filename so the sequence remains understandable
without requiring Git history.

The screenshots are not normative product specifications. They document what
Est looked like at particular points in its development.
